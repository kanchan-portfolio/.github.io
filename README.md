## Features:
- **Categorized Work Exhibition**: Dedicated exhibition page (`work.html`) divided into 9 curated collections with zero photo cropping.
- **Interactive Lightbox**: Fullscreen uncropped viewing with responsive Next/Prev navigation.
- **Embedded 4K Broadcast Player**: Plays verified YouTube masterclasses with sound and controls.
- **Dynamic Hero Preview**: Hovering over any project swaps the main hero photograph immediately.
