# Kanchan - Personal Portfolio Website

Live website: [https://kanchan-portfolio.github.io](https://kanchan-portfolio.github.io)

A modern, responsive, and fast personal portfolio website designed for Kanchan.

## Features
- **Modern Design**: Glassmorphism cards, vibrant gradients, and smooth typography.
- **Dark & Light Mode**: Built-in toggle with automatic system preference detection and localStorage persistence.
- **Fully Responsive**: Optimized for mobile phones, tablets, and desktop displays.
- **Zero Build Tools Required**: Pure standard HTML5, CSS3, and modern JavaScript.
- **Fast & SEO Ready**: Semantic markup, meta tags, and high performance.

## Project Structure
```
├── index.html        # Main landing page structure
├── css/
│   └── style.css     # Styling, theme variables & media queries
├── js/
│   └── main.js       # Dark mode toggle, mobile menu & contact handler
└── README.md         # Documentation
```

## How to Deploy to GitHub Pages

1. Create a repository on GitHub named:
   **`kanchan-portfolio.github.io`**
2. In your terminal, run:
   ```bash
   git init
   git add .
   git commit -m "Initial commit for Kanchan website"
   git branch -M main
   git remote add origin https://github.com/kanchan-portfolio/kanchan-portfolio.github.io.git
   git push -u origin main
   ```
3. GitHub Pages will automatically publish the website at:
   **`https://kanchan-portfolio.github.io`**
