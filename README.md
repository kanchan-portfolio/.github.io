## Features:
- **Interactive Multi-Photo Lightbox**: Clicking any photoshoot row (e.g. Slide 10, Slide 5, etc.) opens a high-res gallery grid to view all frames from that slide.
- **Embedded Broadcast Player**: Clicking any KIFF interview plays the official 4K YouTube broadcast with sound directly on the page.
- **Dynamic Hero Preview**: Hovering over any project swaps the main hero photograph immediately.
- **Self-Contained Offline Assets**: All 51+ slide photos are preserved locally in `assets/`.
