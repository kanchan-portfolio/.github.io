# Felix Kern — Minimalist Photography Portfolio

Live website: [https://kanchan-portfolio.github.io/.github.io/](https://kanchan-portfolio.github.io/.github.io/)

A complete 1:1 replica of **Felix Kern** (`https://felix-kern.webflow.io`).

## Features
- **Typography & Grid**: Monospaced design powered by `IBM Plex Mono` with minimalist borders, uppercase labels, and clean tabular layout.
- **Interactive Project Hover Previews**: Hovering over any selected work (`Scarlet energy`, `Canal morning`, `Chromatic mood`, etc.) automatically swaps the main hero photo to preview that project.
- **Lightbox Examination**: Clicking any work in the list opens a minimalist full-screen modal view of the photograph.
- **Minimalist Menu Controls**: `[+]` and `[-]` expandable navigation bar.
- **Live Status Indicator**: Green indicator showing `Available for work`.
- **Pure Lightweight Code**: Standard HTML5, CSS3, and JavaScript with zero build steps.
